# 数据字典与预处理约定

数据为 UCI Default of Credit Card Clients，30,000 行。实际取值分布见自动生成的 [数据核查记录](data_check.md)。金额单位为新台币。

## 变量

| 变量 | 含义 | 取值 | 预处理 |
|---|---|---|---|
| ID | 客户编号 | 1–30000 | 不作为特征，只用于对齐划分和预测 |
| LIMIT_BAL | 授信额度（含本人及家庭附卡） | 10,000–1,000,000 | 数值 |
| SEX | 性别 | 1 男，2 女 | one-hot |
| EDUCATION | 学历 | 1 研究生，2 大学，3 高中，4 其他；另有未说明的 0、5、6 | 0、5、6 并入 4，再 one-hot |
| MARRIAGE | 婚姻 | 1 已婚，2 单身，3 其他；另有未说明的 0 | 0 并入 3，再 one-hot |
| AGE | 年龄 | 21–79 | 数值 |
| PAY_0, PAY_2 … PAY_6 | 2005 年 9 月至 4 月的还款状态，PAY_0 是最近一个月 | 文档：-1 按时还款，1–8 逾期月数，9 为逾期九个月及以上；另有未说明的 -2 和 0 | 数值，或 one-hot（见下） |
| BILL_AMT1 … BILL_AMT6 | 9 月至 4 月的账单金额 | 可为负（溢缴） | 数值 |
| PAY_AMT1 … PAY_AMT6 | 9 月至 4 月的还款金额 | ≥ 0 | 数值 |
| default payment next month | 下月（2005 年 10 月）是否违约 | 1 违约，0 未违约 | 标签，代码中改名为 `y` |

## 需要知道的几件事

- **列名不连续**：还款状态从 PAY_0 直接跳到 PAY_2，没有 PAY_1。我们保留原列名。
- **PAY 的 -2 和 0**：官方文档没有解释。常见的说法是 -2 表示当月无消费、0 表示使用循环信用（还了最低还款额），但这不是官方定义，报告中只能写成"文档未说明"。两者合计占 PAY_0 的 58%，不能删。
- **PAY 的编码方式是可选项**：`make_preprocessor(pay_onehot=True)` 把 PAY 当类别处理。对 Logistic，五折平均 AP 从 0.503 升到 0.544。树模型自己会切分，用数值即可。
- **特征完全相同的行**：有 108 行，多数是金额全为 0 的不活跃账户，且部分组内标签不同，所以是不同客户。全部保留，但同组的行不跨分区、不跨折。
- **没有缺失值**，所以流程里没有填补步骤。

## 划分

`data/splits/splits.csv`，列为 `ID, partition, fold, group`：`partition` 取 `dev` 或 `test`；`fold` 对开发集取 0–4，对测试集为 -1；`group` 标记特征完全相同的行。

| 测试集 | 9,003 | 22.10% |
| 每折 | 4,195–4,204 | 22.11%–22.15% |
